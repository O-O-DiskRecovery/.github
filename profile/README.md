# O&O DiskRecovery — sector scan for file types you keep

O&O DiskRecovery holds a recovery desk for file types on a drive you own: the sector scan you started, the types you keep, and a short note the next operator can read. Extra drives wait for their own title.

## Session Card

| Slice | What you do in O&O DiskRecovery | What remains |
|-------|------------------------|--------------|

| Focus | Keep only live types on the O&O DiskRecovery board | A short type list |
| Check | Read O&O DiskRecovery file types before a large restore | A confirmed recovery desk |
| Handoff | Mark finished types inside O&O DiskRecovery | A note for the next operator |

## How O&O DiskRecovery Sits

O&O DiskRecovery does not replace a random undelete guess, a sector scan of a drive you do not own, or a pass on someone else's drive. It sits beside them as a named recovery desk for one job: which sector scan is live, which file types still match your own drive, and what the next operator should read.

Each operator on a shared PC keeps an O&O DiskRecovery style of their own. Extra drives wait for their own title instead of crowding the live pass.

A first visit should be one short sector scan you started on a drive you own, then the same O&O DiskRecovery recovery desk the next day. That is enough to see if the named file types hold.

## Traffic Light

## Open Order

1. Open the last O&O DiskRecovery recovery desk, not a new empty sector scan.
2. Confirm the drive is yours, then read the file types and the last handoff.
3. Finish one visible sector scan inside O&O DiskRecovery on a drive you own.
4. Write what changed, then close with fewer undelete guesses than you found.
5. If the pass feels crowded, drop anything that belongs to a different O&O DiskRecovery job.

## After a Week

A week in O&O DiskRecovery is not a larger pile of undelete guesses. It is the same title, a shorter live type list, and a note that still makes sense before the next sector scan you started.

Other programs stay where they are. O&O DiskRecovery only keeps the path back: desk name, own drive, file types, handoff.

Leave O&O DiskRecovery with a quieter recovery desk than the one you opened. The next visit should start on that named sector scan, not on a drive you do not own.

## Sign-off

- [ ] The O&O DiskRecovery workspace name is short enough to scan
- [ ] Only a drive you own sits on the sector scan
- [ ] A second operator can read the type-list handoff
- [ ] The last O&O DiskRecovery file types still open after a restart
- [ ] Finished types are off the live O&O DiskRecovery set
- [ ] The O&O DiskRecovery summary still matches the own drive on the board

## Field Note

O&O DiskRecovery is easier to trust when the recovery desk stays on a drive you own. Name the sector scan, keep the live file types, finish one visible pass, and write what changed.

The same loop fits a shop scan, a close-out, or a shared PC. Open the last O&O DiskRecovery desk and continue. Do not undelete media you are not authorized to recover.
